# font-auto-cut

## 用途

扫描项目中实际用到的文字内容(标题、按钮文案、占位符、固定文案等),从原始字体文件中切出"按需子集",生成体积更小的 woff2 / woff,替换工程内的字体引用。

## 输入

- 原始字体文件(.ttf / .otf / .woff2)
- 项目源代码:`src/**/*.{vue,tsx,less,css}`(扫描其中的文本)
- 可选:`docs/fig_meta/` 中的 Figma 文本节点(避免漏字)

## 输出

- 子集化后的字体文件:`src/assets/fonts/<name>.subset.woff2`
- 字体引用替换:`@font-face` 的 `src` 改为子集文件
- 报告文件(可选):列出抽取的字符表、原始/子集体积、压缩比

## 流程

1. 扫描代码中所有文本(包括属性值、props 默认值、placeholder、模板字面量)
2. 合并 Figma 设计稿中的文本节点(防止动态字符遗漏)
3. 去重得到字符集合
4. 调用工具(常见:`fonttools` / `subset-font` / `glyphhanger`)生成子集
5. 校验子集字体在浏览器中正常渲染
6. 替换工程中的 `@font-face` 引用

## 注意事项

- 中文字体务必包含**全部按钮/标题/固定文案中出现的字符**,否则会出现"豆腐块"
- 如有动态文本(用户输入、接口返回),需保留 fallback 字体
- 子集生成后建议保留 unicode-range,以便 fallback 自然降级

## 与其他 skill 的关系

- 上游:`figma-analyzer`(获取设计稿中的文本)
- 下游:无(产物直接落地到工程)
